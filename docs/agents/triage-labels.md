# Triage Labels

This table maps the skills' canonical triage roles to repository labels. The repository also uses `completed`.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must assess the issue. |
| `needs-info` | `needs-info` | The reporter must supply more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an AFK agent. |
| `ready-for-human` | `ready-for-human` | A person must implement the change. |
| `completed` | `completed` | The work is complete. |
| `wontfix` | `wontfix` | The team will not implement the issue. |

If a skill names a role, use its label from this table. For example, "apply the AFK-ready triage label" means `ready-for-agent`.

Keep the label mapping consistent with the tracker vocabulary.
