# v1.2.1 — Document list and model setup fixes

This maintenance release fixes packet pagination, Smart split document visibility, and empty model settings. It also includes the Workspace Costs dashboard merged since v1.2.0.

## Fixes

- The Document list now loads packets and standalone Documents together, with 50 entries per page. Each packet uses one entry regardless of its child count. Search and filters match packet metadata or its children before pagination, so matching packets remain reachable.
- Smart split children no longer appear briefly as standalone Documents while their parent packet is loading. Live updates preserve parent identity, and list refreshes retain loaded packet entries.
- Active polling continues until both the packet list and the selected packet's details reach a completed or failed state. A completed list entry no longer leaves the selected packet showing stale progress.
- Unconfigured Model gateway settings open on a summary with unavailable values. Choose **Edit** to configure models. **Cancel** and successful clearing return to the summary, and connection testing stays disabled there until settings are configured.

## Workspace costs

- Workspace owners and admins can open **Costs** from the Workspace header to view spending, document cost distributions, and searchable Document and packet breakdowns.
- UTC upload-date ranges cover full history in windows of up to 366 days. Historical summaries build in the background and report when history is incomplete.
- Document and packet deletion retain cost receipts and accounting metadata, including names, Template names, page counts, and packet lineage. Deleting the Workspace removes its accounting history.
- Costs remain gateway-reported USD amounts. Missing costs are unavailable, not estimated or treated as zero. Partial totals identify missing costs, and sampled percentiles are labelled as estimates.

## Upgrading and compatibility

Bun remains pinned to **1.4.2**. The release workflow checks **Ubuntu 24.04 x64 and arm64, and macOS 15 arm64**. The installer recognizes Intel macOS, but this release's CI does not qualify Intel macOS or older operating systems.

Stop the application. Back up its configuration and state. Then run:

```bash
document-extraction update v1.2.1
```

Workspace product schema migration **13** adds cost summaries and accounting snapshots. Historical backfill resumes in the background after restart; it does not repeat model calls or invent missing charges. Existing documents and extraction results remain available. No new required environment variables or provider settings are introduced.

The installer preserves configuration, accounts, documents, and generated secrets. It backs up local state before migration checks. Back up S3 buckets separately. Before a downgrade, restore the backup from before the upgrade.

## Known limits and validation

- The Workspace Costs dashboard requires an owner or admin browser session. Workspace API keys and ordinary members cannot access its endpoints. Document and packet API cost visibility remains unchanged.
- Accounting records deleted before this upgrade cannot be recovered. Cost totals describe reported processing charges, not invoice reconciliation.
- Automatic processing can require user review. Model capability, context, and request-size limits still apply.
- S3 buckets must not use object versioning or Object Lock. Local backups exclude S3 originals. Source downloads do not support byte ranges.

The release workflow validates the exact tagged commit before publishing `install.sh`, `document-extraction.tar.gz`, and its SHA256 checksum. Checks include the platform quality and installer suites, Linux Chromium journeys, and the complete-history secret scan. Automated checks do not qualify live Google sign-in, Cloudflare email delivery, or every third-party model route.
