# v1.2.0 — Document costs and PDF throughput

This release tracks model costs for documents and packets. It also improves PDF processing, navigation, Template assistance, and installation.

## Document and packet costs

- Completed document headers show total cost beside average confidence. Completed packet headers show total cost beside the excluded-page count. Totals stay hidden until completion.
- Hover, focus, or tap a total to see Smart split, Auto template, and Extraction costs in USD.
- The model gateway reads the first valid total from `usage.cost`, `cost_breakdown.total_cost`, or the `x-litellm-response-cost` header. It does not require a particular endpoint hostname or provider selection.
- Each model call has its own accounting record. Reported retries and reassessments contribute to the total without counting a receipt twice.
- Each document receives a share of packet split cost in proportion to its page count. Excluded pages retain their share at packet level. Packet totals include the split and all child selection and extraction calls once.
- Job and packet API responses expose the same cost breakdown. Cached completed documents and live updates preserve cost metadata.

## PDF processing and interface improvements

- PDF inspection and page operations reuse bounded worker processes. Packet processing and extraction alternate within a Workspace so queued packets do not starve their child documents.
- Native PDF requests avoid unnecessary image preparation. Resource checks pause admission when sampling fails, and compatible SQLite runtimes use WAL with full durability.
- Workspace navigation and resource URLs survive refresh and browser history changes. Route recovery preserves Admin access and unsaved JSON drafts.
- The Admin page follows the Studio layout. Template assistant suggestions apply to the active tab. Document views no longer show the redundant parent-packet button.
- The piped installer prepares terminal input before showing setup questions and uses the actual terminal device on macOS.
- Documentation clarifies installation, API use, and browser-only review workflows. New benchmark coverage exercises splitting, automatic selection, and extraction together.

## Upgrading and compatibility

Bun remains pinned to **1.4.2**. The release workflow checks **Ubuntu 24.04 x64 and arm64, and macOS 15 arm64**. The installer recognizes Intel macOS, but this release's CI does not qualify Intel macOS or older operating systems.

Stop the application. Back up its configuration and state. Then run:

```bash
document-extraction update v1.2.0
```

Workspace product schema migration **12** adds model-call accounting. Existing documents and extraction results remain available. Historical model calls have unknown cost; the migration does not invent or backfill charges. No new required environment variables or provider settings are introduced.

The installer preserves configuration, accounts, documents, and generated secrets. It backs up local state before migration checks. Back up S3 buckets separately. Before a downgrade, restore the backup from before the upgrade.

## Known limits and validation

- Costs are endpoint-reported amounts, not invoice reconciliation. Calls without a supported cost field remain unavailable. A `+` marks a known subtotal with missing call costs. A reported zero remains zero.
- Supported cost conventions use USD. Explicitly different currencies are not combined with USD totals. Token counts do not generate price estimates, and charges hidden inside an upstream gateway cannot be reconstructed.
- Automatic processing can require user review. Model capability, context, and request-size limits still apply. Local benchmark results do not establish real-provider throughput.
- S3 buckets must not use object versioning or Object Lock. Local backups exclude S3 originals. Source downloads do not support byte ranges.

The release workflow validates the exact tagged commit before publishing `install.sh`, `document-extraction.tar.gz`, and its SHA256 checksum. Checks include the platform quality and installer suites, Linux Chromium journeys, and the complete-history secret scan. Automated checks do not qualify live Google sign-in, Cloudflare email delivery, or every third-party model route.
