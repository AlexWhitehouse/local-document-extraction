# v2.3.1 — Light theme and quieter field list

This maintenance release adds a light theme and stops the template field list from always showing row controls on the selected field ([#74](https://github.com/AlexWhitehouse/local-document-extraction/pull/74), [#75](https://github.com/AlexWhitehouse/local-document-extraction/pull/75)).

## Interface changes

- **Appearance** in Settings offers **System**, **Light** or **Dark**. Dark stays the default. The choice is kept per browser and applied before the page first draws. **System** follows the operating system as it changes. Light-theme text keeps at least 4.5:1 contrast on every surface.
- In the template editor's field list, the reorder arrows and **More actions** button now appear only when you hover over a row or move keyboard focus into it. This now includes the selected field, whose full name is no longer cut short. The controls stay visible while a row's menu is open.

## Upgrading and compatibility

Bun remains pinned to **1.4.2**. The release workflow checks **Ubuntu 24.04 x64 and arm64, and macOS 15 arm64**. Intel macOS binaries are bundled but not qualified by the CI matrix.

Stop the application. Back up its configuration and state. Then run:

```bash
document-extraction update v2.3.1
```

This release adds no database migrations, and state remains compatible with v2.3.0. Configuration settings and defaults are unchanged.

## Known limits

- The light theme was checked visually on Settings and the Workspace overview. Report any screen where text or controls are hard to read.
- Simulated model tests do not qualify live model routes, Google sign-in or Cloudflare email delivery.
