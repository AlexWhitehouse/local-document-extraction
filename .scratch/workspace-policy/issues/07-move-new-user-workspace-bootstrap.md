## Agent Brief

**Category:** enhancement
**Summary:** Move new-user workspace bootstrap behind the Workspace policy module.

**Current behavior:**
New-user workspace bootstrap is owned by the Better Auth user creation hook. The auth hook directly checks whether the user already has a workspace membership, creates the starter workspace, creates the owner membership, generates and hashes the workspace API key, and inserts the starter invoice template and fields. This keeps durable workspace bootstrap rules and starter template details embedded in auth-provider integration code.

**Desired behavior:**
Better Auth should remain a thin caller that delegates new-user workspace bootstrap to `Workspace policy`. Bootstrap should be idempotent: a user with any existing workspace membership should not receive a duplicate starter workspace. When bootstrap does create a workspace, it should preserve current behavior by creating the workspace, owner membership, workspace API key hash, and starter invoice template content. Starter template creation should be coordinated through a small temporary adapter/interface so the template details can later move behind a dedicated template module rather than becoming permanent Workspace policy knowledge.

**Key interfaces:**
- `Workspace policy` — should expose an intent-shaped bootstrap operation for newly-created users.
- Better Auth user creation hook — should call the Workspace policy bootstrap operation and should not own workspace, membership, workspace API key, template, or template field SQL directly.
- Starter template adapter — should encapsulate starter template creation for bootstrap while preserving the existing starter invoice template behavior.
- Workspace API key hashing — should continue to be owned by Workspace policy so create, bootstrap, rotate, and authenticate paths do not drift.

**Acceptance criteria:**
- [ ] Better Auth user creation calls `Workspace policy` for new-user workspace bootstrap.
- [ ] Bootstrap creates a workspace and owner membership for a user with no existing workspace membership.
- [ ] Bootstrap does not create a duplicate workspace for a user with an existing workspace membership.
- [ ] Bootstrap preserves the current starter invoice template and field creation behavior through a temporary adapter/interface.
- [ ] Better Auth hook no longer owns workspace, membership, workspace API key, starter template, or template field SQL directly.
- [ ] Backend typecheck succeeds.

**Out of scope:**
- Redesigning Better Auth configuration or auth route behavior.
- Changing public workspace, template, extraction, or auth API response contracts.
- Changing the database schema.
- Creating a permanent full template module or redesigning template lifecycle behavior.
