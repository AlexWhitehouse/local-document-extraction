## Agent Brief

**Category:** enhancement
**Summary:** Execute Workspace member removal, admin promotion, and ownership transfer through control-data policy and the real HTTP seam.

**Current behavior:**
The frontend has member-action transitions, confirmations, and toasts, but its route is not implemented. No backend operation enforces the owner/admin/target/self rules or atomically preserves exactly one Workspace owner.

**Desired behavior:**
The session-only member-action route delegates to Workspace control policy. Eligible actors can remove, promote, or transfer ownership; disallowed actors and targets receive stable policy errors. Transfer leaves one owner and keeps the former owner as admin. Successful frontend actions use the domain adapter, refresh Workspace/member/context state, and retain existing feedback.

**Key interfaces:**
- `LocalWorkspaceControl` — performs an atomic member action with actor, target, action, Workspace policy, and exactly-one-owner invariant.
- Workspace member-action HTTP route — accepts a session caller and validated action, never an API key.
- Frontend Workspace request Adapter — owns member-action path/body/result handling outside React.

**Acceptance criteria:**
- [ ] Authorized removal, promotion, and ownership transfer persist correct roles/memberships and retain exactly one owner.
- [ ] Owners, admins, members, targets, self-actions, non-members, and API-key callers receive defined policy outcomes.
- [ ] The controller invokes the adapter and refreshes accepted context and member data after success.
- [ ] Contract tests cover all three mutations and forbidden outcomes through the Fetch application.
- [ ] Focused control/controller checks and build pass.

**Out of scope:**
- Invitation-management listing, Leave Workspace, browser invalidation, and deletion behavior.
- Generic role framework or policy-engine abstraction.

## Completion

Implemented atomic control-data member actions, session-only route and adapter execution, and real Fetch contracts for promotion, transfer, removal, and denied callers. Full backend/frontend tests, lint, backend typecheck, and frontend production build passed.
