## Template Rules
The top-level object must contain:
- "name": required string
- "description": string, use "" if not needed
- "fields": required array with 1 to 50 field objects
Each field must contain:
- "name": required string, unique across fields
- "description": required string, specific extraction instruction
- "data_type": required string, one of:
  - "string"
  - "number"
  - "boolean"
  - "date"
  - "object"
  - "array"
  - "array<object>"
- "required": boolean
Do not include field IDs. The app generates field IDs automatically from field names.
Field names and object column headings should use only letters, numbers, and spaces. Avoid punctuation or symbols.
Use "required": true only for fields that should normally be present on every document of this type. Use false for optional fields.
## Data Type Guidance
Use "string" for:
- Names
- Addresses
- Reference numbers
- IDs
- Codes
- Free text
- Currency labels
- Phone numbers
- Email addresses
Use "number" for:
- Amounts
- Quantities
- Counts
- Percentages
- Numeric totals
- Prices without currency symbols
Use "boolean" for:
- Yes/no values
- True/false values
- Whether something is present
Use "date" for:
- Dates
- Due dates
- Issue dates
- Birth dates
- Expiry dates
Use "array" for:
- A simple list of values
- Example: list of tags, warnings, notes, or reference numbers
Use "object" for:
- One grouped structure with named subfields
- Example: billing address, customer details, supplier details
Use "array<object>" for:
- Repeated rows or table-like data
- Example: invoice line items, prescription lines, bank statement transactions, delivery items
## Object And Array Object Fields
For any field with "data_type": "object" or "array<object>", include an "object_schema" property.
The object_schema must have this shape:
{
  "mode": "table",
  "columns": [
    {
      "heading": "Column Heading",
      "data_type": "string",
      "description": "What this column should contain"
    }
  ]
}
For object_schema column data_type, only use:
- "string"
- "number"
- "boolean"
- "date"
For "array<object>", define one column for each value that should appear in every row.
For "object", define one column for each subfield in the grouped object.
Do not include keys in object_schema columns. The app generates keys automatically from headings.
