# 07 — Make the Local Bun Runtime smoke harness race-free

**What to build:** Let each smoke-test Local Bun Runtime bind its own operating-system-selected port and report its actual origin, so concurrent agents and test workers never rely on a released port reservation.

**Blocked by:** None — can start immediately.

**Category:** enhancement

**Status:** completed

- [x] The child runtime binds port zero itself or is started through an importable bootstrap that returns the actually bound server address.
- [x] Test readiness is based on an explicit reported origin and bounded health check, not on preselecting and releasing an ephemeral port.
- [x] Child-process, server, temporary-state, and fake Model gateway cleanup is registered immediately after each resource is acquired.
- [x] Startup failures report the child output, last health result, elapsed time, and chosen origin.
- [x] One hundred repeated concurrent smoke runs complete without address-in-use or connection-startup failures.
- [x] The stress run leaves no child processes, open listeners, or new temporary state directories behind.
