## Agent Brief

**Category:** enhancement
**Summary:** Extract accepted Workspace context selection into a pure Workspace context Module.

**Current behavior:**
Accepted Workspace context behavior is currently owned inline by the App. Accepted Workspaces are normalized for display, selected Workspace name is derived, selected Workspace context is updated, and Workspace-specific API key restoration happens across App-local logic. This makes Workspace context behavior harder to test without rendering or coordinating App state.

**Desired behavior:**
Accepted Workspace context selection should be owned by a pure Workspace context Module. The Module should normalize accepted Workspaces, derive accepted Workspace context display state, and return the selection updates needed when a user selects an accepted Workspace. The App should remain the adapter for React state, rendering, browser persistence, logging, and applying returned updates.

Pending Workspace invitation behavior should remain unchanged in this slice.

**Key interfaces:**
- Workspace context Module interface — accepts current Workspace context inputs and returns normalized accepted Workspace entries plus accepted Workspace selection outcomes.
- Accepted Workspace selection outcome — includes selected Workspace id, selected Workspace name, cleared pending Workspace invitation selection, and restored Workspace API key value when available.
- Workspace context display model — exposes enough accepted Workspace context state for App rendering without requiring App to reimplement accepted Workspace normalization.

**Acceptance criteria:**
- [x] Accepted Workspaces are normalized through the Workspace context Module before display.
- [x] Selecting an accepted Workspace uses Workspace context Module output to update the selected Workspace context.
- [x] Workspace-specific API key restoration decisions come from the Workspace context Module.
- [x] Pending Workspace invitation behavior remains unchanged by this slice.
- [x] Pure frontend tests cover accepted Workspace ordering, selection, name alignment, API key restoration decisions, and safe default Workspace context behavior.
- [x] Frontend tests and frontend production build pass.

**Out of scope:**
- Changing backend Workspace policy behavior.
- Changing backend route contracts.
- Moving network requests into the Workspace context Module.
- Moving localStorage persistence into the Workspace context Module.
- Moving logging or confirmation prompts into the Workspace context Module.
- Changing pending Workspace invitation locked context behavior in this slice.
