## What to build

Remove active billing behavior from backend and frontend product workflows. Document submission, Template management, Workspace membership, **Workspace API key** behavior, and frontend UI should no longer depend on Stripe, Credits, plan entitlements, billing ledger state, billing operational status, or payment flows. Keep **Product safety limits** and Template shape constraints.

- [x] Billing API routes, Stripe webhook handling, scheduled billing jobs, Credit reservation, billing ledger calls, and plan entitlement gates are removed or made unreachable from active product workflows.

- [x] Workspace membership count and Template count do not block product actions through retired plan/member limits.
- [x] **Product safety limits** still reject unsupported MIME types, oversized Source files, and invalid PDF page-count inputs.
- [x] Frontend billing section, plan comparison, Credit controls, invoice UI, billing operational status, and entitlement-based upload blocking are removed.
- [x] Local schema and required environment configuration no longer require Stripe or billing secrets.
