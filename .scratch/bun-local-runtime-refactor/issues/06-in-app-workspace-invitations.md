## What to build

Preserve **Workspace invitation** lifecycle behavior on local control persistence. Workspace owners/admins can create and cancel pending invitations, invitees see invited workspace entries after signing in with the invited email, and accepting or declining invitations updates local **Workspace membership** and frontend **Workspace selection view** behavior. Invitations remain in-app only and do not generate **Local mail sink** messages.

## Acceptance criteria

- [ ] Workspace owners/admins can create pending **Workspace invitations** through the Bun API.

- [ ] Accepting an invitation creates **Workspace membership** and moves the user into accepted **Workspace context**.
- [ ] Declining an invitation makes it non-actionable and removes it from the invitee's Workspace list.
- [ ] Owners/admins can cancel pending invitations for their Workspace.
- [ ] Invitation creation does not write **Local mail sink** records.
- [ ] Frontend invited workspace entries and locked invitation state continue to work with local control persistence.
- [ ] Tests cover invitation creation, listing, accept, decline, cancellation, authorization, and no outbound invitation mail.
