# Daily JSONL Product Analytics

Category: enhancement
Status: completed

## Parent

## What to build

Replace Workers Analytics Engine with best-effort daily JSONL **Workspace product analytics** logs under local runtime state. Product operations should emit useful operational events without making analytics authoritative or blocking user actions.

## Acceptance criteria

- [x] Analytics events are written to daily JSONL files under local runtime state by default.
- [x] Events cover Template creation/update, Document submission, Extraction completion, and Extraction failure where those product operations exist.
- [x] Events may include stable product IDs and operational metadata needed for local debugging.
- [x] Events do not include extracted answers, evidence text, Source file names, account emails, API keys, Source file binary contents, or Document contents.
- [x] Analytics write failures log a warning and do not fail the product action that emitted the event.
- [x] Tests cover daily file grouping, event serialization, privacy exclusions, and non-blocking failure behavior.
