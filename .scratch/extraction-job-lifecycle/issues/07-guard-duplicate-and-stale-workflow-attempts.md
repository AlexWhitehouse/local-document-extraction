## Agent Brief

**Category:** enhancement
**Summary:** Guard **Extraction job lifecycle** transitions against duplicate and stale workflow attempts.

**Current behavior:**
The **Extraction job lifecycle** Module owns queued creation, processing claims, completion, and terminal failure. Completion and failure operations already use processing state and attempt checks, but duplicate and stale attempt behavior should be explicit, covered through the lifecycle Module **Interface**, and aligned with Cloudflare Workflow retry behavior.

**Desired behavior:**
Lifecycle transitions should reject stale or duplicate workflow attempts so Cloudflare Workflow retries cannot overwrite terminal state. Once an **Extraction job** reaches `completed` or `failed`, later attempts should not complete or fail it again. An attempt older than the current processing attempt should not overwrite newer lifecycle state.

**Key interfaces:**
- **Extraction job lifecycle** Module **Interface** — completion and failure operations should report whether the transition was applied and should protect terminal states.
- Processing claim operation — should prevent stale attempts from becoming current processing attempts.
- Cloudflare Workflow processing flow — should tolerate rejected stale/duplicate lifecycle transitions without corrupting state.
- Attempt tracking fields — should continue to support idempotency and stale attempt rejection.

**Acceptance criteria:**
- [x] Duplicate workflow attempts cannot complete an already terminal **Extraction job** again.
- [x] Duplicate workflow attempts cannot fail an already terminal **Extraction job** again.
- [x] Stale attempts cannot overwrite newer lifecycle state.
- [x] Terminal `completed` and `failed` states are protected from later processing attempts.
- [x] Lifecycle tests cover duplicate and stale attempt behavior through the Module **Interface**.
- [x] Backend typecheck succeeds.

**Out of scope:**
- Removing obsolete durable lifecycle states unless required by the stale-attempt guard.
- Redesigning Cloudflare Workflow retry policy.
- Redesigning AI gateway prompt construction or result normalization.
- Changing **Source file** cleanup behavior.
