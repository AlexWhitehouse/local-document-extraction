## Agent Brief

**Category:** enhancement
**Summary:** Remove `workflow_started` as a durable **Extraction job lifecycle** state.

**Current behavior:**
The queue processing path writes `workflow_started` before creating the Cloudflare Workflow instance. Processing claims still allow `queued` or `workflow_started`, tests still seed or assert `workflow_started`, and the **Extraction job** status type still includes it.

**Desired behavior:**
Cloudflare Workflow instance details should remain implementation metadata, not durable caller-visible **Extraction job lifecycle** state. Processing claims should move eligible **Extraction jobs** from `queued` to `processing` through the lifecycle Module. The durable lifecycle should continue moving toward only `queued`, `processing`, `completed`, and `failed`.

If workflow instance metadata is still needed for tracing or idempotency, preserve it without exposing `workflow_started` as a durable lifecycle state.

**Key interfaces:**
- **Extraction job lifecycle** Module **Interface** — processing claim should not require `workflow_started` as an eligible durable state.
- Queue processing behavior — should start Cloudflare Workflow without writing `workflow_started` as lifecycle state.
- **Extraction job** durable status type — should remove `workflow_started` when no supported lifecycle path uses it.
- Job list/detail responses — should not expose `workflow_started` once removed from durable state.

**Acceptance criteria:**
- [x] No **Extraction job lifecycle** path writes `workflow_started` as a durable caller-visible status.
- [x] Cloudflare Workflow instance details remain implementation metadata if still needed for tracing or idempotency.
- [x] Processing claims move eligible **Extraction jobs** from `queued` to `processing` through the lifecycle Module.
- [x] The **Extraction job** durable status type no longer includes `workflow_started` once supported paths stop using it.
- [x] Tests verify `workflow_started` is not exposed as a durable lifecycle state.
- [x] Backend typecheck succeeds.

**Out of scope:**
- Removing `retryable_failed` from the durable lifecycle.
- Redesigning Cloudflare Workflow itself.
- Changing **Extraction result** persistence.
- Redesigning **Source file** cleanup.
