## Agent Brief

**Category:** enhancement
**Summary:** Preserve **Source file** cleanup after **Extraction job** lifecycle completion.

**Current behavior:**
Successful Cloudflare Workflow processing completes the **Extraction job** through the lifecycle Module, then attempts **Source file** cleanup in the workflow flow. Cleanup records deletion timing separately. Cleanup failures are caught and logged so completed **Extraction results** are not rolled back.

**Desired behavior:**
Successful **Extraction job** completion should still trigger **Source file** cleanup through the Cloudflare Workflow flow. Cleanup failure must not change a completed **Extraction job** back to failed, remove persisted **Extraction results**, or otherwise corrupt durable completion.

This slice should preserve the current product behavior while making the cleanup-after-completion expectation explicit and tested.

**Key interfaces:**
- Cloudflare Workflow processing flow — should attempt **Source file** cleanup after successful completion.
- **Extraction job lifecycle** completion operation — should remain responsible for durable completion and **Extraction result** persistence, not storage deletion.
- **Source file** storage adapter or cleanup operation — should delete the stored **Source file** and record cleanup timing without changing lifecycle completion.

**Acceptance criteria:**
- [x] Successful **Extraction job** completion still attempts **Source file** cleanup.
- [x] Cleanup failure does not change a completed **Extraction job** back to failed.
- [x] Cleanup failure does not remove or mutate persisted **Extraction results**.
- [x] Cleanup timing remains part of the Cloudflare Workflow processing flow.
- [x] Tests cover cleanup after completion and cleanup failure behavior.
- [x] Backend typecheck succeeds.

**Out of scope:**
- Redesigning **Source file** storage naming or bucket bindings.
- Changing when **Extraction results** are persisted.
- Removing obsolete durable lifecycle states.
- Adding a cleanup dashboard, audit log, or manual cleanup tool.
