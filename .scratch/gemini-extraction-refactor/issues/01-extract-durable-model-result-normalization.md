## Agent Brief

**Category:** enhancement
**Summary:** Extract raw model result normalization into a dedicated module while preserving durable **Extraction result** behaviour.

**Current behavior:**
The backend extraction adapter currently mixes model invocation concerns with raw model field result normalization. Existing tests cover normalization behaviour, including date formatting, but the normalizer is not isolated behind its own durable module boundary.

**Desired behavior:**
Raw model field result normalization should be available through a dedicated module with a small public interface. The extraction adapter should remain responsible for calling the Extraction model and returning raw model field results. The Cloudflare Workflow processing path should explicitly normalize raw model field results before completing an **Extraction job**. Existing durable **Extraction result** behaviour should not change.

**Key interfaces:**
- `normalizeModelResults()` — should remain the public behaviour for converting requested **Template fields** plus raw model field results into durable **Extraction result** values.
- `NormalizedModelField` — should continue to represent the normalized result shape consumed by **Extraction job lifecycle** completion.
- Cloudflare Workflow processing flow — should continue to call model extraction first, then normalize, then complete the **Extraction job**.

**Acceptance criteria:**
- [ ] Raw model field result normalization is exposed through a dedicated module with a small public interface.
- [ ] The extraction adapter remains responsible for model invocation, not durable **Extraction result** coercion.
- [ ] The Cloudflare Workflow processing path still normalizes raw model field results before completing an **Extraction job**.
- [ ] Existing normalization behaviour for dates, numbers, booleans, objects, arrays, missing fields, invalid types, confidence, and evidence is preserved.
- [ ] Existing normalization tests are preserved and pass against the new module boundary.
- [ ] Backend typecheck passes.

**Out of scope:**
- Changing the Extraction model invocation path.
- Changing completed **Extraction job** API response shape.
- Wiring or removing extraction options.
- Changing **Extraction job lifecycle** states or retry semantics.
