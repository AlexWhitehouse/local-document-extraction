## Agent Brief

**Category:** enhancement
**Summary:** Prune stale non-Gemini provider configuration so backend configuration matches the supported Gemini-only extraction runtime.

**Current behavior:**
The extraction runtime is intentionally Gemini-only and already uses explicit model and gateway configuration for execution. Application-owned backend configuration still declares stale non-Gemini provider/API-key fields and a redundant gateway route value, which makes the system appear to support provider switching that is out of scope for this refactor.

**Desired behavior:**
Application-owned environment types and Worker configuration should only expose configuration that is still needed for Gemini **Document** extraction: model selection and Workers AI Gateway execution. Redundant gateway route configuration should be removed, and persisted gateway metadata should continue to use the actual gateway identifier used by extraction.

**Key interfaces:**
- `Env` configuration shape — should no longer include unsupported non-Gemini provider/API-key fields or redundant gateway route configuration.
- Worker configuration variables — should keep model selection and gateway execution values while dropping unused provider/API-key and redundant route values.
- Extraction gateway metadata — should continue to persist the actual gateway identifier used by the **Extraction job lifecycle**.
- Generated Worker configuration types — should be regenerated through the appropriate tooling if they need to change; do not hand-edit generated output.

**Acceptance criteria:**
- [x] Application-owned environment types no longer declare unused non-Gemini provider/API-key fields.
- [x] Application-owned Worker configuration no longer declares unused non-Gemini provider/API-key values.
- [x] Model selection configuration remains available.
- [x] Gateway execution configuration remains available.
- [x] Redundant gateway route configuration is removed from application-owned configuration.
- [x] Persisted gateway metadata continues to use the actual gateway identifier used by extraction.
- [x] Generated configuration files are not manually edited unless regenerated by the appropriate tooling.
- [x] Backend typecheck passes.

**Out of scope:**
- Supporting OpenAI, Anthropic, or any other non-Gemini provider.
- Designing provider switching or a provider plugin system.
- Changing Gemini source submission, response parsing, or model result normalization.
- Changing **Document** submission API behaviour, **Extraction job lifecycle** states, retry semantics, or completed response shape.
