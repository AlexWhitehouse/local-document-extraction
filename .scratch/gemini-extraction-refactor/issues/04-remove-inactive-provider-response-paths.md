## Agent Brief

**Category:** enhancement
**Summary:** Limit extraction response parsing to Gemini-compatible response text plus simple direct text shortcuts.

**Current behavior:**
The extraction adapter parses Gemini candidate text responses, simple direct text responses, and inactive provider-specific response shapes. The OpenAI-style and Anthropic-style branches suggest unsupported runtime behaviour even though the refactor intentionally narrows extraction to Gemini.

**Desired behavior:**
Extraction response parsing should accept Gemini-compatible candidate text containing the expected JSON result payload. It should also retain simple direct text shortcuts where Workers AI normalizes text output. Provider-specific OpenAI and Anthropic response branches should be removed without changing retryable failure behaviour for invalid JSON, missing result arrays, empty responses, or unreadable response content.

**Key interfaces:**
- Model response parsing inside the extraction adapter — should return raw model field results from supported Gemini-compatible JSON content.
- `RetryableError` behaviour — should continue to represent transient or model-output parsing failures that Cloudflare Workflow can retry.
- Raw model field result shape — should remain compatible with the dedicated model result normalizer and downstream **Extraction job lifecycle** completion.

**Acceptance criteria:**
- [x] Gemini candidate text responses containing valid JSON parse into raw model field results.
- [x] Simple direct text responses containing valid JSON still parse into raw model field results.
- [x] OpenAI-specific response parsing is removed.
- [x] Anthropic-specific response parsing is removed.
- [x] Invalid JSON model content still produces the existing retryable error behaviour.
- [x] Missing model result arrays still produce the existing retryable error behaviour.
- [x] Tests cover successful Gemini response parsing and retryable parse failures.
- [x] Backend test suite and typecheck pass.

**Out of scope:**
- Supporting OpenAI, Anthropic, or any other non-Gemini provider.
- Changing model result normalization rules for durable **Extraction results**.
- Changing **Extraction job lifecycle** states, retry semantics, or completed response shape.
- Pruning environment configuration; that is covered by a separate issue after inactive runtime paths are removed.
