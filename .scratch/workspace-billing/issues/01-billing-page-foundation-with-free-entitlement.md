# Billing Page Foundation With Free Entitlement

Category: enhancement
Type: AFK
Status: completed

## Parent

## What to build

Create the first end-to-end Workspace billing slice without Stripe or paid Credits. Every existing and new Workspace should resolve to the Free plan by default, expose an owner-only Billing page with current Free entitlement, zero Included Credits, current-period page capacity, plan limits, and no payment controls yet. Non-owners should not see the Billing page, but product surfaces may show limited Billing operational status when needed.

This slice should establish the code-owned non-enterprise plan catalog, Billing period anchor rules for Free Workspaces, a dedicated session-only billing summary endpoint, frontend Billing page navigation for Workspace owners, and tests that prove owner/non-owner boundaries.

## Agent Brief

**Category:** enhancement
**Summary:** Establish the first Workspace billing slice by resolving every Workspace to the Free entitlement and exposing an owner-only Billing page with no Stripe or paid Credit flows.

**Current behavior:**
Workspace access, Workspace roles, Workspace API keys, starter Templates, and workspace-scoped product routes already exist, but Workspace billing is not implemented. Existing and newly created Workspaces do not resolve through a billing entitlement model, there is no dedicated owner-facing billing summary endpoint, and the frontend has no Billing page navigation or billing summary display.

**Desired behavior:**
Every Workspace should resolve to a Free Active entitlement by default unless a later billing state exists. Free entitlement should be code-owned, deterministic, and visible through a dedicated owner-facing summary path. The summary must show zero Included Credits separately from current-period page capacity, the Free plan limits, current Billing period information anchored to the Workspace creation time, and no payment controls. Only the current Workspace owner has Workspace billing authority for the owner-facing Billing page and detailed billing summary. Workspace admins and members must not see Billing page navigation, and Workspace API keys must not be able to read owner-facing billing summaries.

**Key interfaces:**
- Non-enterprise billing plan catalog - define Free, Pro, and Max in code even though this slice only exposes Free behavior. The Free catalog entry must include Included Credits, Template/member/field/table-column limits, monthly Plan page limit, API access flag, and tax-exclusive per-page catalog price.
- Active entitlement resolver - resolve missing Workspace billing control data to the Free entitlement, using the Workspace creation time as the Free Billing period anchor.
- Billing period calculation - compute the current Free Billing period and remaining current-period page capacity from the Workspace creation time and current time.
- Owner-facing billing summary endpoint - provide a session-only Workspace billing summary requiring Workspace billing authority; reject Workspace API-key authentication and non-owner sessions.
- Workspace listing response - keep owner-only billing details out of normal Workspace listing responses.
- Billing page navigation and page state - show the Billing page only to Workspace owners and display Free entitlement, Credits, remaining page capacity, plan limits, and any scheduled next entitlement when present.
- Billing operational status - any non-owner status exposed outside the Billing page must remain limited to operational block context and must not expose invoices, payment methods, exact prices paid, or owner-only controls.
