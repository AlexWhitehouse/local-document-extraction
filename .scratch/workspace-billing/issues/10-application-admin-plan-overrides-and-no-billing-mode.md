# Application Admin Plan Overrides And No-Billing Mode

Category: enhancement
Type: AFK
Status: completed

## Parent

.scratch/workspace-billing/PRD.md

## What to build

Add Application admin billing controls for no-payment Plan overrides and No-billing mode. Application admins should be able to assign time-bounded Free/Pro/Max overrides without payment, grant the target plan's Included Credits for covered Billing periods, inspect active/scheduled billing state, and place a Workspace in No-billing mode with the Enterprise limit profile and no charges.

This slice should extend the Application admin surface with billing management while keeping the owner Billing page separate.

## Acceptance criteria

- [x] Application admins can view Workspace billing state in an Application admin billing view.
- [x] Application admins can create a no-payment-required Plan override targeting Free, Pro, or Max with start, end, reason, and creating admin.
- [x] Active Plan override takes precedence over Enterprise, self-service subscription, and Free entitlement.
- [x] No-payment-required Plan override activates without Stripe payment.
- [x] No-payment-required Plan override grants target plan Included Credits for each covered Billing period.
- [x] Plan override expiry falls back to active self-service subscription entitlement if one exists, otherwise Free.

## Agent Brief

**Category:** enhancement
**Summary:** Add Application admin no-payment Plan overrides and No-billing mode for Workspace billing.

**Current behavior:**
Workspace billing has the foundational Free/Pro/Max catalog, owner Billing page, Billing ledger, manual Goodwill Credit grant/revoke flow, prepaid Credit reservation enforcement, Plan limit overage enforcement, Stripe Credit pack purchases, self-service Pro/Max subscriptions, subscription changes/cancellation, unpaid state handling, and deletion billing guards.

Application admin billing controls currently cover manual Goodwill Credit adjustments only. There is no Application admin billing view for inspecting the full active/scheduled Workspace billing state, no time-bounded no-payment Plan override model, no override entitlement precedence, no automatic Included Credit grants for override-covered Billing periods, no No-billing mode, and no No-billing usage ledger entry when Documents are submitted without Credits or invoices.

**Desired behavior:**
Application admins should be able to inspect Workspace billing state and create no-payment-required Plan overrides for Free, Pro, or Max with start time, end time, reason, and creating admin recorded. An active Plan override should activate without Stripe payment, take precedence over Enterprise, self-service subscription, and Free entitlements, and expire back to an active self-service subscription entitlement when one exists or Free otherwise. Plan overrides must not target Enterprise or No-billing mode.

No-payment-required Plan overrides should grant the target plan's Included Credits for each covered Billing period. Grants must be idempotent so repeated admin actions, retries, or period-boundary processing cannot double-grant the same included allowance for the same Workspace, target plan, and Billing period.

Application admins should also be able to enable and disable No-billing mode for a Workspace with a reason. No-billing mode should sit above Plan overrides in Active entitlement precedence, use the Enterprise limit profile, bypass Credits, invoices, usage charges, and Plan page limit enforcement, and still preserve product safety limits and abuse/rate limits. Document submissions accepted under No-billing mode should record No-billing usage entries in the Billing ledger with the same submission metadata captured by Credit reservations.

Owner Billing page summaries, Workspace listing operational summaries, and Application admin billing summaries should reflect active Plan override or No-billing entitlement without exposing owner-only billing details to non-owner members. All Application admin billing actions should write Application admin billing audit log entries with actor, timestamp, reason, before/after values, and Workspace.

**Key interfaces:**
- Active entitlement resolver — should support No-billing mode, active Plan override, Enterprise, active self-service subscription, and Free precedence in that order.
- Workspace billing control data — should store Plan override state, No-billing state, creating/disabling admin, reasons, start/end times, and audit-relevant before/after snapshots.
- Billing period and Included Credit grant behavior — should grant override Included Credits once per covered Billing period and fall back deterministically after override expiry.
- Billing ledger RPC surface — should support idempotent Included Credit grants for override-covered periods and No-billing usage entries with Document submission metadata.
- Document submission billing authority — should choose between Credit reservation and No-billing usage entry based on the resolved Active entitlement before durable product side effects.
- Plan limit enforcement and Billing operational status — should evaluate limits from active override or No-billing entitlement, including the Enterprise limit profile for No-billing mode.
- Application admin billing API/UI — should let Application admins inspect Workspace billing state, create Plan overrides, enable/disable No-billing mode, and review relevant audit information.
- Owner Billing page contract — should show the active Plan override or No-billing entitlement and the next scheduled entitlement change while keeping customer-facing activity separate from admin audit notes.
