# Start Using The App

Document Extraction helps you turn PDFs and image Documents into structured data. You work in a Workspace, create Templates that describe the data you need, then upload Documents and review the extracted results.

## Sign In

Open the Document Extraction app URL provided by your organisation.

You can sign in with:

- Email and password.
- Google, when enabled for your account.

If you create an account with email and password, verify your email before continuing. Password reset links are available from the sign-in screen.

## Choose A Workspace

A Workspace is where your team's Templates, Documents, Extraction jobs, members, API keys, and billing live.

After signing in:

1. Select an existing Workspace from the Workspace list.
2. Accept or decline any pending Workspace invitations.
3. Create a new Workspace if you need a separate area for another team, project, or customer.

Your browser remembers the last accepted Workspace you selected.

## Understand The Main Areas

| Area | What You Do There |
| --- | --- |
| Workspace | Rename the Workspace, invite members, manage roles, and generate API keys. |
| Templates | Create reusable extraction schemas. |
| Documents | Upload Documents, track processing, and review results. |
| Billing | View plan, Credits, usage, and subscription actions when you are the Workspace owner. |
