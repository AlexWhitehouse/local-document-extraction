# First Extraction

Use this walkthrough to extract structured data from a Document for the first time.

## 1. Select Your Workspace

Choose the Workspace where you want the Template and Document history to live. If you were invited to a Workspace, accept the invitation first.

## 2. Create A Template

Open **Templates** and create a Template that describes the data you want back.

For example, an invoice Template might include:

- Invoice Number
- Supplier Name
- Invoice Date
- Invoice Total
- Line Items

Each field needs a name, a description, and a data type. Good descriptions improve extraction quality because they explain exactly what the field means.

## 3. Upload A Document

Open **Documents**, choose your Template, and upload a supported Document:

- PNG
- JPEG
- WebP
- PDF

The app queues an Extraction job for each uploaded Document.

## 4. Wait For Processing

Queued and processing Documents update in the Documents area. When a job completes, select it to review extracted results.

If a job fails, the Document row shows failure details. You can adjust the Template or try a clearer Source file before submitting again.

## 5. Review Results

Each result corresponds to a Template field. Depending on the Template and settings, results may include:

- The extracted answer.
- Confidence.
- Evidence from the Source file.
- A status such as `ok`, `not_found`, or `unreadable`.

## 6. Reuse Or Refine

Templates are reusable. Upload more Documents with the same Template, or edit the Template when you need different fields or clearer instructions.
