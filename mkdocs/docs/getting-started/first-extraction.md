# First Extraction

1. Select an accepted Workspace.
2. Open **Templates** and create a Template with field names, descriptions, and data types.
3. Open **Documents**, select the Template, and upload a PNG, JPEG, WebP, or PDF.
4. Wait for the queued job to reach `completed` or `failed`.
5. Select a completed job to review its structured field results.

Templates are reusable and can be refined as document layouts change.
